# 금융거래조회서 자동 생성

한국공인회계사회 2020 금융거래조회서 양식 6종과 채권채무조회서를 한글(HWP) 양식 그대로 채운다. 결과는 조회처별 HWP와 PDF 파일로 만든다.

- 금융기관 조회처 목록(control sheet)을 읽는다. 용도에 맞는 양식을 골라 기관별로 조회서를 만든다.
- 채권채무조회서는 거래처 입력 엑셀을 따로 받아 만든다.
- 우편으로 보낼 조회서는 인쇄용 합본 PDF로 한 번 더 묶는다.

양식 6종은 은행, 비은행, 여신, 보험, 증권, 보증기관이다.

## 필요한 것

- Windows
- 한글(한컴오피스). 한글을 직접 조작해서 문서를 채우고 PDF로 저장한다. 한글 2022에서 확인했다.
- exe로 쓸 때는 Python이 필요 없다.

## 사용법 (exe)

`조회서생성.exe`를 실행한다. 같은 폴더에 `templates/` 폴더가 있어야 한다.

### 1. 기본정보 탭

| 묶음 | 항목 |
|---|---|
| 감사인 | 감사인명, 사업자등록번호, 담당 공인회계사, 전화, 팩스, 이메일, 수수료 환급계좌·은행·예금주 |
| 회사 | 회사명, 법인등록번호, 대표자, 사업자등록번호(여러 개 가능) |
| 날짜 | 작성일, 조회기준일, 요구서 유효기간 |

- 날짜는 `2026-12-31` 형식으로 넣는다.
- 조회기준일을 넣으면 요구서 유효기간과 양식 탭의 기간이 자동으로 계산된다. 계산된 값은 직접 고칠 수 있다.
- 입력값은 창을 닫거나 생성 버튼을 누를 때 `입력값.json`에 저장된다. 다음 실행 때 그대로 불러온다.

### 2. 금융거래조회서

1. 창 아래쪽 **금융기관 조회처 목록**에서 control sheet 파일을 고른다.
2. 양식 탭(은행 ~ 보증기관)에서 그 양식을 받을 조회처와, 그 양식에만 필요한 입력을 확인한다.
3. **[금융거래조회서 생성]**을 누른다.

양식별로 필요한 입력은 다음과 같다. 이번 목록에 대상이 없는 양식의 입력은 비어 있어도 된다.

| 양식 | 추가 입력 | 조회서에 들어가는 곳 |
|---|---|---|
| 은행 | 어음·수표 교부기간, 당좌거래 기간 | 6번, 10번 |
| 증권 | 거래내역 기간 | 9번 |
| 여신·보험·보증기관 | 법인인감증명서 첨부 (여/부) | 요구서 붙임 "(첨부여부 : 여 ○ 부 __)" |
| 비은행 | 없음 | — |

### 3. 채권채무조회서

1. **채권채무** 탭에서 **[빈 입력 양식 만들기]**를 눌러 거래처 입력 엑셀을 만든다.
2. 엑셀을 채우고 저장한 뒤 그 파일을 고른다. 거래처별 합계와 별지 여부가 미리 보인다.
3. **[채권채무조회서 생성]**을 누른다.

### 한글 보안 팝업

실행 중에 "한글 문서에 접근하려는 시도가 있습니다" 창이 뜨면 **모두 허용**을 누른다.

- 한글 자동화 보안모듈을 등록하지 않은 PC에서는 실행할 때마다 이 창이 뜬다.
- 응답하지 않으면 생성이 멈춘 채로 기다린다.

## 입력 파일

### 금융기관 조회처 목록 (control sheet)

- 첫 번째 시트를 읽는다.
- 6행이 열 제목이고, 8행부터 조회처 데이터다.
- 6행의 B·D·E·G열 제목이 달라지면 양식이 바뀐 것으로 보고 멈춘다.

| 열 | 내용 | 쓰임 |
|---|---|---|
| B | 용도 | 양식 선택 |
| C | 관련 계정과목 | 로그·생성기록 표시 |
| D | 금융기관명 | 수신처 |
| E | 지점명 | 수신처 |
| F | 본점/지점/부 | 지점명이 비어 있고 "본점"이면 수신처에 "본점"을 붙인다 |
| G | 온라인 여부 | O면 전자조회 대상으로 본다 |

**용도 값과 양식**

| B열 용도 | 양식 |
|---|---|
| 은행 | 은행조회서 |
| 비은행금융회사 | 금융거래조회서(비은행 금융회사용) |
| 여신전문금융회사 | 금융거래조회서(여신전문금융회사용) |
| 보험회사 | 보험거래조회서 |
| 증권회사 | 금융거래조회서(증권회사용) |
| 보증기관 | 금융거래조회서(보증기관용) |

**처리 규칙**

- 용도·기관명·지점이 같은 행(계좌가 여러 개인 경우)은 조회서 한 통으로 묶는다.
- 용도가 비었거나 위 표에 없는 행, 기관명이 빈 행은 만들지 않는다. 대신 로그에 행 번호를 남긴다.
- 온라인 여부가 모두 O인 조회처는 `전자조회 가능(비상용)` 폴더에 만든다. 이 조회서는 합본에 넣지 않는다.
- 온라인 O와 공란이 섞인 조회처는 우편 발송으로 분류하고 경고를 남긴다.

### 채권채무 거래처 입력

[빈 입력 양식 만들기]로 만든 파일의 `채권채무` 시트를 쓴다. 한 줄에 계정 하나씩 적는다.

- 1행의 열 제목으로 열을 찾는다. 그래서 열 순서를 바꾸거나 다른 열을 추가해도 된다.
- 같은 파일의 `작성방법` 시트에도 설명이 있다.

| 열 | 필수 | 설명 |
|---|---|---|
| 조회서번호 | 선택 | 비우면 001, 002 … 순번 |
| 거래처명 | 필수 | 같은 거래처의 줄은 한 통으로 묶음 |
| 구분 | 필수 | 채권 = 당사가 받을 금액(1번 표), 채무 = 당사가 지급할 금액(2번 표) |
| 계정과목 | 필수 | |
| 적요 | 선택 | |
| 금액 | 필수 | 숫자 |
| 비고 | 선택 | |

## 결과물

```
out/<회사명>_<조회기준일>/
  우편 발송/              01_은행_○○은행 ○○지점.hwp / .pdf …
  전자조회 가능(비상용)/   온라인 O 조회처
  합본_우편발송.pdf        우편 발송 대상만 순번대로 묶은 인쇄용 PDF
  생성기록.xlsx            사용한 입력값, 사업자등록번호, 생성 목록
  채권채무/
    001_거래처명.hwp / .pdf …
    합본_채권채무.pdf
    생성기록_채권채무.xlsx
```

- 합본은 이번 실행에서 만든 파일만 묶는다.
- 값을 채운 뒤 쪽수가 늘어나면(긴 값으로 줄이 넘친 경우) 로그에 경고를 남긴다. 그 조회서는 PDF를 열어 확인한다.

## 자동으로 정해지는 값

| 항목 | 규칙 |
|---|---|
| 요구서 유효기간 | 조회기준일 3개월 뒤 월말 |
| 어음·수표 교부기간 (은행) | 조회기준일 1년 전 다음 날 ~ 조회기준일 |
| 당좌거래 기간 (은행), 거래내역 기간 (증권) | 조회기준일 30일 전 ~ 조회기준일 다음 달 말일 |
| 사업자등록번호 2개 이상 | 요구서에 "별도 첨부"로 적고, 사업자등록번호 목록 쪽을 각 조회서 끝에 붙임 |
| 채권채무 — 채권 또는 채무가 없음 | 표에 "해당사항 없음", 합계 ₩0 |
| 채권채무 — 한쪽이 3줄 초과 | 표에 2줄 + "기타 / 별지 참조 (N건)". 전체 내역 별지 3장(감사인보관용·회신용·회사보관용)을 조회서 끝에 붙임 |

## 원본 양식과 다른 점

- **채권채무조회서**
  - 작성일 줄과 "회사명 대표이사 (인)" 줄을 오른쪽 정렬로 바꿨다.
  - 원본은 공백으로 글자를 밀어 정렬한 방식이었다. 그래서 회사명이 길면 줄이 넘쳐 한 통이 두 장씩 됐다.
  - 문구는 바꾸지 않았다.
- **은행조회서 7-7쪽 서명란의 "201__년"**: 원본 오타를 그대로 두었다. 은행이 채우는 칸이다.
- **증권 양식 7-1쪽의 "발급번호" 칸**: 비워 둔다.

## 하지 않는 것

- 조회서 안에서 회사가 기입하는 칸은 채우지 않는다. 금융상품 계좌·잔액, 대출 내역 같은 칸이다.
- 우편 주소 라벨은 아직 만들지 않는다. control sheet에 주소 열이 없어서다.
- 별지는 조회서 맨 끝에 모아서 붙인다. 보관 구분 쪽마다 바로 뒤에 끼워 넣지는 않는다.

## 개발

### 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 탭 화면(tkinter). exe의 시작점 |
| `generate.py` | 입력 검사, 조회서 생성, 합본, 생성기록. 명령줄로도 실행할 수 있다 |
| `hwpauto.py` | 한글 자동화(COM) 래퍼: 열기, 찾아 바꾸기, 표 칸 이동, 문서 끼워 넣기, 저장 |
| `make_template.py` | 원본 HWP 양식의 빈칸을 `{{표시어}}`로 바꿔 `templates/`를 만든다 |
| `build.py` | PyInstaller로 `dist/조회서생성/`을 만든다 |
| `templates/` | 생성에 쓰는 템플릿 7종 |

### 환경 준비

```
uv venv .venv --python 3.13
uv pip install --python .venv\Scripts\python.exe pyinstaller pywin32 openpyxl pypdf
```

### 실행

```
.venv\Scripts\python app.py                       # 화면
.venv\Scripts\python generate.py "조회처 목록.xlsx"  # 명령줄, 금융거래조회서만 (입력값.json의 값을 씀)
```

### 템플릿 다시 만들기

양식이 개정됐을 때만 다시 만든다.

```
.venv\Scripts\python make_template.py            # 전체
.venv\Scripts\python make_template.py 은행 증권   # 일부
```

- 원본 양식은 `../[별첨]2020 금융거래조회서 양식/`에서 읽는다. 이 폴더는 저장소에 없다.
- 각 규칙은 바꿀 곳이 몇 군데인지 정해져 있다. 원본에서 찾은 개수가 다르면 멈춘다.
- 양식이 바뀌어 규칙이 맞지 않을 때는 두 가지 방법이 있다.
  - `make_template.py`의 규칙을 고친다.
  - 한글에서 템플릿을 열고 빈칸에 `{{회사명}}`처럼 표시어를 직접 쳐 넣는다.

### exe 빌드

```
.venv\Scripts\python build.py
```

- 결과는 `dist/조회서생성/`에 생긴다.
- 템플릿은 함께 복사된다. `입력값.json`은 넣지 않는다.

### 저장소에 올리지 않는 것

`.gitignore`에 등록된 파일들이다.

- `입력값.json`: 담당 CPA 연락처와 환급계좌가 들어 있다.
- `out/`: 고객사 조회서가 들어 있다.
- 빌드·실행 환경 파일: `dist/`, `build/`, `.venv/`
